# rankipv4

Rank and reshape ipv4 text streams with deterministic transforms.

**Site:** https://theworker02.github.io/rankipv4/

## Install / run

```bash
git clone https://github.com/theworker02/rankipv4.git
cd rankipv4
node src/cli.js
node --test
```
